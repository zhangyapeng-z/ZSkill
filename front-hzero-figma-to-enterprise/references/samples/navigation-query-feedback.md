# Figma Samples - Navigation, Query, Feedback

## Included cases
- `H-ZERO 流光蓝导航与反馈组件`
- `H-ZERO 流光蓝查询组件`
- `H-ZERO 流光蓝反馈组件`

## Shared takeaways
- These are navigation/query/feedback component showcase nodes.
- They confirm component families and visual states, not backend behavior.
- They do not confirm route, API, permission, or response contract.

## PageSchema hints
- Use `custom`, `navigation`, `query`, `feedback`, `steps`, `breadcrumb`, `pagination`, or `result` candidates as visual regions.
- Treat query widgets as candidate filters only; field names and query protocol remain `missing`.
- Treat feedback states as visual states; error codes, loading sources, and retry behavior remain `missing`.
