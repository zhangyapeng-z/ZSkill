# Figma Samples - Data Display and Selector

## Included cases
- `H-ZERO 流光蓝数据展示组件`
- `H-ZERO 流光蓝选择器组件`

## Shared takeaways
- These are data-display and selector showcase nodes.
- They help map visual families to component candidates.
- They do not confirm lookupCode, lovCode, return shape, or submit mapping.

## PageSchema hints
- Use `dataDisplay`, `selector`, `description`, `tag`, `tree`, `transfer`, or `picker` candidates only when visually supported.
- Selector visuals can suggest `candidateType`, but lookup/LOV codes, options source, return shape, and submit value stay `missing`.
- For display widgets, data source, formatter, permission, and refresh behavior stay `missing`.
