3. 卡片布局测试

🎯 优势 1：完美的中文支持

Playwright 使用真实的 Chromium 浏览器引擎渲染页面，因此能够完美支持中文、日文、韩文等 Unicode 字符。

🎨 优势 2：完整的 CSS 支持

支持现代 CSS 特性，包括：

  • Flexbox 和 Grid 布局
  • 自定义字体（@font-face）
  • CSS 变量和 calc() 函数
  • 媒体查询（@media print）

🚀 优势 3：JavaScript 支持

如果 HTML 中包含 JavaScript 动态生成的内容，Playwright 会等待页面完全渲染后再生成 PDF，确保内容完整性。

5. 分页控制测试

以下内容使用了 page-break-inside: avoid; 样式，避免卡片在分页时被切断。

📌 重要提示

如果你在 PDF 中发现表格或卡片被分页切断，可以在 CSS 中添加：

table, .card, .avoid-break {
    page-break-inside: avoid;
}

这样可以确保元素在打印时保持完整。
