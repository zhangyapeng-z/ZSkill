# 财务与指标

SaaS财务压缩参考：32个带公式和基准的指标、诊断框架，以及功能投资、渠道评估和价格变动的决策逻辑。

## SaaS收入与增长指标

### 核心收入指标

| 指标 | 公式 | 基准 |
|------|------|------|
| **收入** | 期内所有客户付款总和 | 同比增长 >20%（因阶段而异） |
| **ARPU** | 总收入 / 总用户 | B2C: $5-50/月; B2B: $50-500+/月; 追踪趋势 |
| **ARPA** | MRR / 活跃账户 | SMB: $100-$1K/月; 中端: $1K-$10K; 企业: $10K+ |
| **ACV** | 每合同年经常性收入（不含一次性费用） | SMB: $5K-$25K; 中端: $25K-$100K; 企业: $100K+ |
| **MRR/ARR** | MRR = 重复订阅总和; ARR = MRR x 12 | 追踪组成部分：新客户 + 扩展 - 流失 - 缩减 |
| **毛收入vs净收入** | 净 = 毛 - 折扣 - 退款 - 积分 | 退款 >10% = 产品问题; 折扣 >20% = 定价权问题 |

**ARPA/ARPU组合分析：** 每账户平均席位数 = ARPA / ARPU。高ARPA + 低ARPU = 货币化不足的席位。低ARPA + 高ARPU = 小交易规模。

### 留存与扩展指标

| 指标 | 公式 | 基准 |
|------|------|------|
| **流失率（客户）** | 流失客户 / 期初客户 | 月: <2% 优秀, 2-5% 正常, >5% 危机 |
| **流失率（收入）** | 流失MRR / 期初MRR | 年: <10% 优秀, 10-30% 正常, >30% 危机 |
| **NRR** | (期初ARR + 扩展 - 流失 - 缩减) / 期初ARR x 100 | >120% 优秀; 100-120% 良好; <90% 问题 |
| **扩展收入** | 追加销售 + 交叉销售 + 使用增长 | 应为总收入的20-30% |
| **快速比率** | (新MRR + 扩展MRR) / (流失MRR + 缩减MRR) | >4 优秀; 2-4 健康; <2 漏水桶 |

**流失复合：** 3%月流失 ≠ 36%年流失。使用 `年流失 = 1 - (1 - 月流失)^12`。3%月流失 ≈ 31%年流失。5%月流失 ≈ 46%年流失。

### 分析框架

**收入组合：** 产品/细分收入 / 总收入 x 100。没有单一产品 >60%理想。前客户 <10%收入；前10客户 <40%。

**队列分析：** 按加入日期对客户分组，追踪随时间的留存/扩展。较新队列应表现相同或优于较旧队列。如果新队列退化，PMF正在侵蚀——停止扩展，修复产品。

## 单位经济学与效率

### 客户级盈利能力

| 指标 | 公式 | 基准 |
|------|------|------|
| **毛利率** | (收入 - COGS) / 收入 x 100 | SaaS: 70-85% 良好; <60% 令人担忧 |
| **CAC** | 总S&M支出 / 新获客客户 | 企业: $10K+ 可接受; SMB: <$500 目标 |
| **LTV（简单）** | ARPU x 平均客户生命周期（月） | 必须为CAC的3倍+ |
| **LTV（更好）** | ARPU x 毛利率% / 月流失率 | 用于决策 |
| **LTV:CAC** | LTV / CAC | <1:1 不可持续; 1-3:1 边际; 3-5:1 健康; >5:1 投资不足 |
| **回收期** | CAC / (月ARPU x 毛利率%) | <12月 优秀; 12-18 正常; >24 令人担忧 |
| **贡献利润率** | (收入 - 所有可变成本) / 收入 x 100 | 60-80% 良好; <40% 令人担忧 |
| **毛利率回收** | CAC / (月ARPU x 毛利率%) | 与上面回收期相同公式；使用此版本 |

**COGS包括：** 托管、基础设施、支付处理、客户入职成本。
**可变成本包括：** COGS + 支持 + 支付处理 + 可变客户成功。

**关键洞察：** 36个月回收期的4:1 LTV:CAC是现金陷阱。8个月回收期的3:1 LTV:CAC对增长更好。

### 资本效率

| 指标 | 公式 | 基准 |
|------|------|------|
| **燃烧率（总）** | 每月总现金支出 | 取决于上下文 |
| **燃烧率（净）** | 每月现金支出 - 每月收入 | 早期 <$200K 可管理; >$500K 需要收入路径 |
| **现金跑道** | 现金余额 / 月净燃烧 | 12+ 良好; 6-12 正常; <6 危机。在6-9个月，不是3个月融资。 |
| **OpEx** | S&M + 研发 + G&A | 应比收入增长慢 |
| **净收入** | 收入 - COGS - OpEx | 早期负数正常; 成熟 10-20%+ 利润率 |

**营运资金：** 预付的年度合同增加现金。月度账单延迟收款。基于现金的跑道 ≠ 基于收入的跑道。

### 效率比率

| 指标 | 公式 | 基准 |
|------|------|------|
| **40法则** | 收入增长% + 利润率% | >40 健康; 25-40 正常; <25 令人担忧 |
| **魔法数字** | (Q收入 - 上Q收入) x 4 / 上Q S&M支出 | >0.75 扩展; 0.5-0.75 优化; <0.5 修复GTM |
| **经营杠杆** | 收入增长率 vs OpEx增长率 | 收入增长必须超过OpEx增长 |

**各阶段40法则：** 早期 = 60%增长 + (-20%)利润率 = 40。增长 = 40% + 5% = 45。成熟 = 20% + 25% = 45。

## 业务健康诊断

### 四维框架

1. **增长与留存** -- 收入增长、NRR、流失、快速比率
2. **单位经济学** -- CAC、LTV、LTV:CAC、回收、毛利率
3. **资本效率** -- 燃烧、跑道、40法则、魔法数字
4. **战略位置** -- 市场定价、护城河、集中度、杠杆

### 阶段特定基准

| 指标 | 早期 (<$1000万ARR) | 增长 ($1000万-$5000万) | 规模 ($5000万+) |
|------|---------------------|------------------------|-----------------|
| 增长YoY | >50% | >40% | >25% |
| LTV:CAC | >3:1 | -- | -- |
| NRR | -- | >100% | >110% |
| 毛利率 | >70% | -- | -- |
| 40法则 | -- | >40 | >40 |
| 魔法数字 | -- | >0.75 | -- |
| 利润率 | 负数正常 | -- | >10% |
| 现金跑道 | >12个月 | -- | 正现金流 |

### 红旗严重程度

**关键（立即修复）：** 跑道 <6月、LTV:CAC <1.5:1、队列环比流失加速、NRR <90%、魔法数字 <0.3。

**高优先级（季度内修复）：** 40法则 <25、回收 >24月、快速比率 <2、毛利率 <60%、前10客户收入集中 >50%。

**中优先级（6个月内解决）：** NRR 90-100%、魔法数字 0.3-0.5、负经营杠杆、稳定但高流失（>5%月）。

### 诊断评分

- **健康：** 所有维度达到/超过阶段基准，无关键红旗，趋势改善。行动：积极扩展。
- **中等：** 1-2个维度需要关注，中等优先级红旗。行动：在进一步扩展前修复具体问题。
- **令人担忧：** 多个关键红旗，2+维度有问题。行动：紧急干预——停止扩展，修复留存和单位经济学。
- **危急：** 跑道 <3月或LTV:CAC <1:1。行动：生存模式——紧急融资或削减燃烧50%+。

## 功能投资分析

### 收入连接类型

1. **直接货币化** -- 新层级、付费附加组件、使用费。计算：客户群 x 采用率 x 价格。
2. **留存改善** -- 解决流失原因。计算：LTV影响 = 生命周期增加 x 基数 x ARPU x 利润率。
3. **转化改善** -- 试用到付费提升。计算：试用用户 x 转化提升 x ARPU。
4. **扩展推动者** -- 追加/交叉销售路径。计算：基数 x 扩展率 x ARPU增长。

### ROI阈值

| 场景 | 构建如果 | 不构建如果 |
|------|----------|------------|
| 直接货币化 | ROI >3倍第一年 | 下行情况毛利率为负 |
| 留存功能 | LTV影响 >10倍开发成本 | 回收超过平均客户生命周期 |
| 战略覆盖 | 竞争护城河、平台推动者、合规 | "战略"没有明确定义 |

### 成本结构检查

- 一次性：开发成本（团队规模 x 时间）
- 持续：COGS影响（托管、基础设施）+ OpEx（支持、维护）
- 利润率影响：如果COGS >20%预计收入，标记利润率稀释
- 贡献利润率：(收入 - COGS) / 收入 必须保持正数

### 决策模式

**立即构建：** ROI >3:1（直接）或LTV影响 >10:1（留存）、正贡献利润率、回收 <客户生命周期。

**为战略原因构建：** ROI <2:1但有竞争护城河、平台推动者或合规。限制投资，监控采用，6个月重新评估。

**不构建：** ROI <1:1、负贡献利润率、无战略价值。考虑减少范围或改变货币化。

**以后构建：** 采用或影响假设的高度不确定性。先用调查、原型、流失访谈验证。

## 渠道经济学

### 渠道评估框架

从四个维度评估每个渠道：

1. **单位经济学** -- CAC、LTV、LTV:CAC、回收（按渠道，不是混合）
2. **客户质量** -- 队列留存、流失率、NRR、ICP契合度（按渠道）
3. **可扩展性** -- 魔法数字、可寻址量、CAC趋势
4. **战略契合度** -- 细分匹配、销售模式兼容性

### 渠道决策矩阵

| LTV:CAC | 回收 | 客户质量 | 可扩展性 | 决策 |
|---------|------|----------|----------|------|
| >3:1 | <12月 | 良好留存 | 高容量 | **积极扩展** |
| 2-3:1 | 12-18月 | 平均留存 | 中等 | **测试和优化** |
| <2:1 | >18月 | 差留存 | 低 | **杀死或修复** |

### 扩展标准

全部满足时扩展：LTV:CAC >3:1 AND 回收 <12月 AND 魔法数字 >0.75 AND 客户质量 >= 混合。增加预算50-100%，每周监控CAC增加 >20%（饱和信号）。

### 优化手册

- **如果CAC太高：** 改善转化率、降低每次点击成本、缩短销售周期。
- **如果LTV太低：** 改善渠道队列入职、瞄准更高价值细分、添加扩展计划。
- **如果目标偏离：** 缩小受众、改善信息、添加资格预审步骤。
- 时间线：4-8周。目标是LTV:CAC >3:1，回收 <12月。如果无法实现，杀死。

### 杀死标准

LTV:CAC <1.5:1且无明确改善路径。将预算重新分配到表现最好的渠道。例外：战略渠道（企业现场销售）获得上限支出和6-12个月跑道证明。

### 增量性

用对照组测试。只计算真正增量的转化。重新营销活动经常声称归功于本来会自然发生的转化。

## 定价分析

### 定价变动类型

- **提价** -- 仅针对新客户（保护现有）vs 所有客户
- **新的高级层级** -- 追加销售路径，观察蚕食
- **付费附加组件** -- 功能货币化；如果以前免费则评估留存风险
- **基于使用量** -- 按单位收费（席位、API调用、存储）；实现自然扩展收入
- **折扣策略** -- 年度预付（现金流）、批量（更大交易）、促销（紧迫性）
- **包装变动** -- 重新捆绑功能、改变定价指标

### 五维影响评估

1. **收入：** ARPU提升 = (新ARPU - 当前ARPU) / 当前ARPU。预计MRR增加 = 基数 x ARPU提升。
2. **转化：** 更高价格可能降低试用到付费。模拟转化下降及其对新客户量的影响。
3. **流失：** 模拟场景——保守（+2pp流失）、基准（+1pp）、乐观（+0）。流失驱动的MRR损失 = 额外流失% x 基数 x 新ARPU。
4. **扩展：** 变动是否创造追加销售路径？基于使用量的定价使客户增长时自然扩展。
5. **CAC回收：** 更高ARPU = 更快回收，但更低转化 = 更高有效CAC。计算净影响。

### 决策模式

**广泛实施：** 净收入明显为正（>10% ARPU提升，<5%流失风险），最小转化影响。保护现有客户。

**先测试（A/B）：** 影响不确定，中等风险。用100+客户每队列测试60-90天。如果转化保持在可接受范围内则推出。

**修改方法：** 原始提案太冒险。选项：更小提价、保护现有客户、分段定价（仅提高企业）。

**不改变：** 流失驱动的损失超过收入增长，或高竞争压力。专注于留存/扩展。

### 年度折扣护栏

年度预付限制在10-15%。30%年度折扣破坏LTV。平衡现金流改善与收入保护。

## 质量门

### 虚荣指标陷阱

- **无利润的收入：** $100万在80%利润率 >> $200万在20%利润率
- **ARPU增长来自组合转变：** ARPU上升是因为小客户流失，不是因为货币化改善
- **注册无转化：** 10,000注册在5%转化 = 500客户。用付费计算CAC，不是注册
- **参与无收入：** 功能增加参与但不增加留存或货币化——不是业务成果
- **毛收入掩盖净缩减：** 追踪折扣和退款；毛收入上浮20%但折扣翻倍 = 净持平

### 混合指标危险

永远不要用混合平均做决定。始终按以下细分：
- **渠道：** $10K CAC的一个渠道隐藏在$500混合CAC中
- **细分：** $100 ARPU混合$10 SMB和$1,000企业——对决策无用
- **队列：** 混合3%流失掩盖新队列6%和旧队列1%
- **产品：** -5%增长、正在死去的67%遗留产品被+80%增长的33%新产品掩盖

### 常见计算错误

- **无利润的LTV：** 使用 `ARPU x 利润率% / 流失`，不是 `ARPU x 生命周期`
- **流失乘以12：** 流失是复合的。3%月 = 31%年，不是36%
- **无利润的回收：** 使用毛利率回收，不是收入回收
- **无回收的CAC比较：** $5K CAC在24月回收比$8K CAC在8月回收更差
- **无跑道的40法则：** 3个月跑道的40分毫无意义
- **无回收的LTV:CAC：** 48月回收的6:1比率是现金陷阱

### 决策反模式

- 当快速比率 <2时扩展获客（漏水桶）
- 不模拟流失场景就提价
- 仅从低流失（不是扩展驱动）庆祝NRR >100%
- 使用"战略"作为构建低ROI功能的万能借口
- 同时修复一切而不是优先处理前1-3个问题
- 在3-6个月和100+客户数据之前杀死渠道
- 过度依赖一个渠道（>50%获客）
- 破坏LTV的年度折扣 >15%短期现金
- 用10个客户测试定价（需要每队列100+才有意义）
- 庆祝0.5%基础的功能请求而忽视其他99.5%
