# 职业与领导力

涵盖PM到总监和总监到VP/CPO职业转型的压缩知识模块、诊断辅导逻辑、高管入职方法论，以及每个层级的命名失败模式。

## 高度-视野框架

两个轴定义PM到总监的转变：

**高度（范围）**
- PM：客户问题、个人功能、冲刺优先级、特定团队动态。
- 总监：产品组合、跨职能系统、组织动态、预算分配、市场定位。

**视野（时间）**
- PM：天、周、冲刺。最多一个季度。
- 总监：以季度为起点。年规划周期、多年度策略。

**服务员vs.餐厅运营商** —— 核心类比：

| 维度 | PM（服务员） | 总监（运营商） |
|------|-------------|---------------|
| 焦点 | 单个用餐者体验 | 整个系统：人员配备、利润、菜单、供应商 |
| 权威 | 有影响力但无控制 | 组合决策、预算、资源分配 |
| 成功指标 | 第七桌开心 | 餐厅盈利、一致、可扩展 |
| 客户关系 | 直接、日常、亲密 | 聚合模式、市场队列 |

### 四个转变区域

1. **思维高度** — 停止直接解决个人问题。开始设计解决一类问题的系统和团队。
2. **身份转变** — 停止纠结于个人用户人物角色。开始思考买家人物角色、市场队列、组织利益相关者、高管动态。
3. **英雄综合征恢复** — 停止成为救火英雄。开始从团队成功中获得满足感。你的产品是你的团队，不是路线图。
4. **方向创建** — 停止等待上面的明确方向。开始创建向下传递的上下文级联，将策略转化为团队清晰度，即使输入不完整。

### 级联上下文地图

当方向模糊时，总监级联而不是等待：

1. 倾听顶层策略（QBR、高管沟通）
2. 提取领导层陈述的3-5个关键优先事项
3. 映射："我们的BU如何实现这些？"
4. 映射："我们的产品组合如何实现？"
5. 映射："我团队的具体责任是什么？"
6. 传达级联 — 不仅是内容，而是为什么它向上连接

模板：
```
公司优先事项：[领导层的话]
BU翻译：[你的BU如何贡献]
组合翻译：[你的产品如何贡献]
团队责任：[每个团队拥有什么]
为什么重要：[什么改变，什么不变]
```

核心原则：即使上面的方向不完整，总监的工作是向下填补空白。创造不完美但有用的清晰度是总监技能。

### 命名失败模式（PM到总监）

**英雄综合征** — 跳进去直接解决问题。退回到旧的可见IC胜利奖励循环。代价：你作为总监表现不佳，同时过度运作作为高级IC。你的团队不发展。

**流程过敏** — 让高绩效PM运行独立的操作手册。代价：跨营销、财务、领导的利益相关者无法综合不一致的输出。

**取悦型领导** — 希望团队喜欢你。避免艰难反馈。为保持关系而说YES。代价：混淆"受欢迎"与"有效"。

**即时满足陷阱** — 读领导力书籍，获取认证，问"我需要做什么才能获得晋升？"代价：总监准备度需要实战故事和真实的谦逊，不是学习。

**非黑即白思维** — "这看起来很明显。""为什么一切都是政治性的？"代价：低信心快速决策造成下游混乱。灰度才是实际地形。

## PM到总监转型

### 四种辅导情况

| 情况 | 描述 | 辅导优先级 |
|------|------|----------|
| 准备中 | 还是PM，迈向总监 | 识别最弱的转变区域；练习级联思维；审计英雄综合征习惯 |
| 面试中 | 积极内部或外部搜索 | 每个转变区域构建一个故事；用总监语言重构PM胜利；准备诚实回答差距问题 |
| 新就任 | 担任总监前6个月 | 立即运行级联上下文地图；将1对1重新框架为战略高度；明确命名模糊；抵制过早重组 |
| 重新校准 | 担任总监；有东西坏了 | 跟踪IC vs辅导时间比率（目标：20% IC）；识别什么让你停留在英雄综合征；创建 deliberate handoffs |

### 就绪信号（准备中）

从四个差距区域评估：
1. **思维高度** — 还默认直接解决客户问题？
2. **利益相关者导航** — 在政治、高管动态、跨职能影响方面有困难？
3. **战略叙事** — 在领导对话中无法将工作与公司策略联系起来？
4. **方向创建** — 等待上面的清晰度而不是创建它？

发展时间线很重要：离目标6个月+ = 刻意构建。3-6个月 = 发出就绪信号，准备经理对话。actively applying = 转向面试准备。

### 面试准备

- 将高度-视野框架作为学习会议来工作：在每个部分后，识别你自己的故事。
- 每个转变区域构建一个具体故事。用区域名称作为结构。
- 重构PM胜利：不要以"我交付了X"开头。以"我的团队面临的战略问题是[X]。这是我如何思考组合权衡的。"
- 对于差距问题："这是差距，这是我一直如何发展的，这是我在前90天会专注学习的。"诚实加计划胜过回避。

### 新就任辅导

针对继承团队没有明确方向的挑战具体指导：
1. 本周运行级联上下文地图。不要等待完美清晰度。
2. 重定向1对1："帮我看看你的产品如何与我负责的业务目标联系起来。"
3. 明确命名模糊："这是我目前最好的翻译。我会在两周内更新。"
4. 等60-90天再重组。先了解什么在运作。

### 重新校准辅导

对于12个月后仍在做IC工作的总监：
- 跟踪比率：大多数人在60-70% IC工作。目标是20%。
- 识别根本原因：(a)信任自己的判断超过团队，(b)团队未发展，(c)从IC行为获得奖励信号。
- 为前3个IC活动创建 deliberate handoff，带有书面"做得好"标准。
- 改变奖励循环：注意更安静的总监会谈（PM独自完成了艰难的利益相关者对话，团队创建了自己的级联）。
- 如果根深蒂固1-2年：考虑角色是否合适。高级IC / 首席PM是合法路径。

## 总监到VP/CPO转型

### 三个P框架

VP/CPO责任涵盖三个维度：
- **产品** — 组合决策、路线图策略、产品家族一致性
- **实践** — 工作如何完成；过程纪律、执行一致性、跨职能运营节奏
- **人** — 主要焦点：组织结构、人才匹配、领导发展、设定和检查期望

大多数总监在产品方面强，在实践方面合格。在VP/CPO转型中最常出问题的是人。

### 授权神话

错误信念："一旦我到了那里，我终于有权做我一直知道是对的的。"
现实：约束不会消失，它们改变形状。PM = 3x3魔方。总监 = 5x5。VP = 7x7。CPO = 9x9。相同原则；每个决策的爆炸半径指数级增长。

### VP到CPO范式转变

| 维度 | VP心态 | CPO心态 |
|------|--------|---------|
| 核心问题 | "我们发布什么？" | "产品组织对什么业务成果负责？" |
| 语言 | 产品词汇（功能、路线图、冲刺） | 业务词汇（ROI、收入、留存、利润率、EBITDA） |
| 主要客户 | 终端用户 | 可能是投资者、买家或董事会——取决于业务上下文 |
| 主要团队 | 产品组织 | 高管团队（CEO、CFO、CRO、CMO） |

### 各层级时间视野

| 级别 | 短期 | 长期 |
|------|------|------|
| IC | 冲刺 | 季度 |
| 总监 | 季度 | 1-2年 |
| VP | 1-2个季度 | 3年 |
| CPO | 1-2个季度 | 3-5年 |

季度交付不会停止。在每个级别，短期责任与长期视野并行运行。

### 联盟建设（高管级别）

没有高管联盟，你就是"活死人"。要求：
- 每周与同行高管接触（CRO、CFO、CMO）— 不是年度路线图审查
- 主动沟通权衡："因为你Y，这个季度你不会得到X，这是为什么"
- 在宣布决定之前而不是之后让人跟上来
- 了解每个同行的真实优先事项，而不只是表面说的

### CEO面试问题（接受前）

在接受VP/CPO角色前探查的五个问题：

1. "在前90天和第一年，你对产品组织有什么期望？" — 揭示不现实的转型时间线。
2. "你们产品团队中的明星是谁，为什么？" — 揭示CEO的认知和偏见。
3. "谁有差距，为什么？" — CEO认为组织弱点是什么？
4. "我应该提前了解哪些约束？" — 你实际拥有的决策权限。
5. "这个角色在一年后的成功是什么样的？" — 强制具体性。模糊答案是红旗。

**红旗：** "你不能改变现有路线图"（失去基本权威）。"在六个月内转型组织"（为失败做准备）。CEO的人才评估与你在别处听到的不一致。

### VP/CPO就绪度评估

四种辅导情况镜像总监顾问：

| 情况 | 关键评估领域 |
|------|-------------|
| 准备中 | 三个P中哪个最弱？你在高管理解方面的暴露如何？ |
| 评估/面试中 | 你能展示高管级别思维 vs 总监级别工作吗？你运行过CEO面试问题吗？ |
| 新就任 | 在不过早行动的情况下定位？高管动态导航？人员/组织评估？揭示未写出的策略？ |
| 重新校准 | 仍在总监级别运作？高管关系破裂？组织表现不佳？成功标准不清晰？ |

## 高管入职（30-60-90）

### 顾问心态

以评估组织的外部顾问身份进入每个新的VP/CPO角色，在你负责改变之前。
- 在诊断之前先观察。在声明之前先提问。
- 了解方向盘如何连接到舵轮——组织图是假的；映射实际现实。
- 不要扔大红色开关。先了解继承的结构控制什么。
- 提前协商：告诉你的老板明确表示第1个月是学习阶段。

### 阶段1：诊断（第1个月）

**目标：** 建立证据体系。了解现实，不是官方版本。

1. **访谈所有人** — 直接下属、跨职能同级（CRO、CFO、CMO、工程领导）、PM样本。问题："什么在运作？" / "什么不在运作？" / "我在官方简报中不会听到什么？" / "我应该和谁谈谈？"
2. **让人来找你** — 主动安排时间的人有议程。揭露它，评估它，记下信号。
3. **做详细笔记** — 谁说的，什么可能是他们的激励，多个独立来源是否确认。
4. **抵制行动** — 当你看到有问题的东西，记下来。你还不知道为什么它坏了，它连接到什么，或以前的修复尝试失败了什么。

**可交付成果：** 组织现实 的详细笔记本，尚未解释。

### 阶段2：验证（第2个月）

**目标：** 揭示模式，挑战结论，识别人才情况。

1. **与你的老板核实现实** — "我听到[X]。这与我来时理解的不同。帮我理解历史。"
2. **映射未写出的策略** — 问："当事情变得困难时，组织实际上优化什么？"答案通常与使命声明不同。
3. **完成人员评估** — 未经雕琢的钻石（有能力，被低估，没有支持者）。通过听"她有能力但没人给她困难问题"或注意谁提供最原始信息来找到他们。他们成为早期关键盟友。
4. **识别3-5个最高杠杆变化** — 不是完整转型计划。这些成为第3个月议程。

**可交付成果：** 解释性组织评估，带人才地图和初始战略优先事项。

### 阶段3：用证据行动（第3个月）

**目标：** 基于收集的证据做出决定。

1. **分享组织评估** — 将发现带给老板和直接下属。透明度建立信任，并在你行动之前揭露分歧。
2. **运行第一个级联上下文地图** — 即使你上面的策略仍然模糊，也要创建方向。团队一直在等待上下文。
3. **开始人才对话** — 钻石： stretch assignment。角色不对：关于不匹配和选项的诚实对话。离开：诚实和关怀，不是回避。
4. **刻意建立高管联盟** — 开始与CRO、CFO、CMO每周对齐实践。不要等他们被惊讶。

**可交付成果：** 共享评估、初始战略方向、3-5个活跃变化正在进行，带明确理由。

### 人员评估类别

**未经雕琢的钻石：** 有能力、被低估、没有支持者。通过听"她有能力但没人给她困难问题"或注意谁提供最原始信息来找到他们。他们成为早期关键盟友。

**角色不对的强人：** 优势与范围不匹配。常见于快速增长后收购或基于任期的晋升组织。如果可以辅导就辅导，找另一个角色，或分道扬镳。三者都比保持不匹配好。

## 质量门

### 所有转型的反模式

**过早行动** — 在建立证据体系之前进行结构改变。第1个月的变化保证昂贵的逆转。

**顾问模式太久** — 第3个月还在收集信息。组织信心侵蚀。根据当前最佳证据行动。

**追名** — 优化晋升表现而不是建立实际肌肉。面试官和经理检测到差异。

**跳过高度转移** — 使用策略词汇同时做出冲刺级别决定（高度剧场）。如果你在细节中，拥有它。如果不在，完全委托。

**授权幻想** — 接受VP/CPO角色期望约束消失。它们扩大，不是消失。

**联盟忽视** — 将高管同级关系视为次于管理直接报告。在VP/CPO，高管团队是你的主要运营环境。

**最响声音偏见** — 从第1个月遇到的最健谈的人形成早期意见。只对3+独立来源确认的主题采取行动。

**混淆VP和CPO** — 将总监到VP和VP到CPO视为不同规模相同移动。VP到CPO是质变（产品第一到业务第一），不是范围扩展。

**一次性级联** — 在年度规划时运行一次上下文地图，从不重访。在主要拐点重访：季度规划、高管变化、转向、重组。

**善良混淆** — 保护团队免受艰难决定，将反馈软化为无意义。要透明关于"为什么"。你分享的应该是诚实和可操作的。
