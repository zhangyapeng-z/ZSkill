# 起始提示语

安装后直接粘贴使用。技能会用你的语言回复（中英文均可）。

## 首次使用提示语

```
帮我写一个通知偏好功能的产品需求文档。做合理假设并标注出来。
```

```
分析这些指标：MRR 5万美元，500个客户，毛利率80%，月流失率8%，CAC 500美元。
```

```
评审这个路线图，指出哪些地方证据薄弱、哪些权衡没有说明、以及哪里被利益相关者主导了。
```
