# 微前端 - 设计与契约

## 阅读路由
- 微前端 设计、契约冻结、question gate、事实确认或资源选择时读取。

## 事实确认契约
- 仅依赖自身说明和本地 `references/` 给出安全流程、硬规则、输出结构和不确定性处理。
- 本地 references 是模式和候选事实，不等同于目标项目契约。
- 输出具体微前端配置、qiankun 生命周期、加载优先级、远程地址、暴露组件或排障结论前，必须先从项目源码、构建产物、运行环境或明确文档确认；确认不了就列为待确认项。
- 部署地址、部署目录、public url、构建产物路径、`microConfig` 中的远程地址、`window.mfRemotes` 运行时地址和 Network 失败请求必须分别确认，不得相互推导。
- `remoteEntry.js` 的实际访问 URL 只能来自已确认的 `microConfig`、运行时 `window.mfRemotes`、部署产物说明或浏览器 Network 失败请求；不得依据包名、路由名、菜单名或环境名编造。
