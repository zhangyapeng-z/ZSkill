# 编写规范

## 颗粒度
- 前台门户需求**不描述视觉细节**（颜色、间距、圆角、字体等）
- 只描述三件事：**要素（有什么）、交互（点击跳转到哪）、数据来源（数据从哪来）**

## 交互描述规则
1. 每个可点击元素必须有一条交互记录
2. 使用 `→` 表示跳转，如：`点击"查看详情" → 跳转**服务详情页**`
3. 跳转目标用**加粗**标注
4. 携带参数的情况用 `（携带XX参数）` 后缀说明
5. 纯展示元素标注"纯展示，无点击跳转"

## 数据来源描述规则
1. 明确接口/模块名称
2. 明确取数条件（状态、排序、数量限制）
3. 跨模块数据源特别标注（如"专家管理独立模块"）
4. 标签/分类等枚举值标注来源（如"取自【商品小类】"、"取自机构标签体系"）

## 要素描述规则
1. 枚举类要素列出完整枚举值或注明"取自XX数据源"
2. 卡片类要素以列表形式描述每个字段
3. 原型ID取 HTML 中 `id` 属性值

## 核对规则
1. 逐区块对照 HTML 原型，每个可见元素必须出现在文档中
2. 每个交互入口必须有对应的交互说明
3. 核对清单格式：
```
| 区块 | 原型要素 | 文档是否覆盖 |
|:---|:---|:---:|
```

## 页面间关系
1. 首页"查看更多" → 对应列表页
2. 列表卡片"查看详情" → 对应详情页
3. 服务详情/专家详情中的机构名称 → 机构详情页
4. 机构详情中的服务卡片 → 服务详情页；"查看全部" → 服务列表页

## 公共规则（汇总 PRD 时）
1. 标签体系说明（商品标签 vs 机构标签独立）
2. 专家数据源说明（独立模块）
3. 默认排序规则
4. 案例数据脱敏规则
