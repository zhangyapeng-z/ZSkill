# 门户端 HTML 原型转 PRD — 文档模板

本文档定义了从门户端 HTML 原型生成需求说明文档的标准章节结构。

---

## 单页面需求说明结构

每个页面按以下结构输出需求说明：

```
# 需求说明-[页面名称]

## 一、页面要素总览
| 序号 | 区块 | 原型ID | 说明 |
|:-:|:---|:---|:---|

## 二、各区块要素与数据来源
### X.1 区块A
**要素**：...
**交互**：
| 元素 | 交互 |
|:---|:---|
**数据来源**：...

### X.2 区块B
...

## 三、要素核对清单
| 区块 | 原型要素 | 文档是否覆盖 |
|:---|:---|:---:|
```

## 字段规范

### 交互表
仅描述交互行为（点击跳转到哪个页面 / 触发什么行为），不描述视觉样式：
```
| 元素 | 交互 |
|:---|:---|
| 按钮/链接名称 | 点击 → 跳转/行为描述 |
```

### 数据来源
描述数据从哪个接口/模块获取、取数条件：
```
**数据来源**：XX接口，条件：状态=正常，按XX排序取前N条
```

### 跳转描述
统一使用 `**目标页面名**` 格式：
- 跳转**服务列表页**
- 跳转**机构详情页**

### 原型ID
直接取原型 HTML 中的 id 属性值（如 sec-hero、sec-list）
