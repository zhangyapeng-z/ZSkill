# Figma 到企业前端 - 验证与运行态

## 阅读路由
- Figma 到企业前端 验证、构建、浏览器检查、运行态判定或输出检查时读取。

## 输出要求
方案或分析输出：
1. 设计输入和可用证据。
2. 页面模式识别。
3. Figma 缓存状态和文件路径。
4. `PageSchema` 摘要。
5. UI 设计回读表和 UI Contract seeds，并记录 `layoutAuthority`、`businessAuthority`、`uiBusinessConflicts`。
6. 推荐组件体系和映射优先级。
7. 工程集成点。
8. 待确认项和降级边界。
9. 验证方式。

设计交接输出：
1. PageSchema、映射说明或片段摘要。
2. Figma/PageSchema 依据。
3. UI Contract seeds、UI 来源优先级和禁止反模式。
4. 使用的自定义组件、HZERO 或 Choerodon 映射模式。
5. 未确认但未阻塞的事项。
6. 返回 `frontend-auto-agent` 的实现交接建议和验证规划。
