# 构建与产物加载 - 验证与运行态

## 阅读路由
- 构建与产物加载 验证、构建、浏览器检查、运行态判定或输出检查时读取。

## 输出检查清单
- 问题阶段归类。
- `BuildStagePacket` 中各项证据的已确认/待确认状态。
- 本地开发服务/HMR、父模块构建、子模块/子包编译、构建产物和运行时加载边界明确。
- 推荐检查命令或配置项。
- `build:ms` 验证不得直接执行包内 `transpile`；实际运行后必须记录 `packages/<module>/lib`、`dist`、`.umi`、`.umi-production` 副产物检查结论。
- 证据不足时原样输出 `候选命令`、`待确认`、`项目证据`。
- 远程元数据和访问路径检查。
- 增量构建风险。
- 待确认信息。
- 验证步骤。
