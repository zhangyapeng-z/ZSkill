## 一句话定位
在 1000+ 技能生态里，按真实用例快速找到对的那一个，并判断它靠不靠谱。

## 能力介绍（粘贴到平台表单）
技能导航与选型方法论。① 11 大功能分类地图：文档处理、开发与代码工具、数据与分析、商业与营销、沟通与写作、创意与媒体、生产力与组织、协作与项目管理、安全与系统、辅助技术、应用自动化（含 CRM/工单/邮件/DevOps/存储/表格/日历/社媒/营销/客服/电商/设计/分析/HR/自动化/会议 17 个子类）；② 选型判断流程：按真实用例而非技术名词检索，先定位 2-3 个可能命中的分类，再查重、评估、验证；③ 六维质量标准：真实用例、可移植性（遵循开放标准而非绑定平台）、依赖（零依赖或明确可装）、产出可验证、描述质量（说清做什么+何时用）、触发精度（该触发时触发，不该触发时安静）；④ 自建技能的贡献规范：基于真实用例、先查重、遵循结构模板、跨平台测试、文档清晰。含维护建议：技能太多会互相抢触发，同领域保留一个主力；三个月没用过的卸载。
