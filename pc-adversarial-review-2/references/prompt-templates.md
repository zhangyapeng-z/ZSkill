# 提示词模板库

本文件提供常见场景的提示词模板，复制后替换占位符即可使用。

---

## 一、快速审查模板（极速模式）

适用场景：简单内容、快速确认、小白提问

### 模板 1：方案快速把关

```
帮我快速审一下这个方案，看看有没有明显的问题。

【方案内容】
（粘贴你的方案文本）

【背景信息】
- 这是给谁用的：（如：内部团队、外部客户）
- 要达到什么目的：（如：说服老板批预算、给客户看）
- 你最担心什么：（如：逻辑不通、预算不够）
```

### 模板 2：代码快速检查

```
帮我看看这段代码有没有明显的 bug 或安全问题。

【代码】
（粘贴代码）

【背景信息】
- 这段代码是做什么的：（如：用户登录、数据查询）
- 用的什么语言/框架：（如：Node.js + Express）
- 最担心什么问题：（如：安全、性能）
```

### 模板 3：文档快速过目

```
帮我快速看看这篇文章写得怎么样，有没有明显的问题。

【文章】
（粘贴文章）

【背景信息】
- 给谁看的：（如：公众号读者、公司内部）
- 想达到什么效果：（如：说服读者、传递信息）
```

## 二、标准审查模板（标准模式）

适用场景：中等复杂度、需要完整问题清单

### 模板 4：方案标准审查

```
帮我用标准模式审查一下这个方案。

【方案名称】
（方案名称）

【方案内容】
（粘贴完整方案文本）

【上下文】
- 所属领域/行业：（如：互联网、教育、金融）
- 目标受众：（如：投资人、用户、内部团队）
- 核心目标：（如：拿到融资、提升用户留存、优化流程）
- 已知约束：（如：预算有限、时间紧迫、技术栈限制）

【重点关注】
（可选，指定你特别想让专家关注的方面，如：风险、落地可行性、竞品差异化）
```

### 模板 5：代码标准审查

```
帮我审查一下这段代码，用标准模式。

【代码】
（粘贴代码）

【上下文】
- 语言/框架：（如：Python / Django）
- 功能描述：（这段代码是做什么的）
- 技术环境：（如：数据库类型、部署环境）

【重点关注】
（可选：安全性、性能、可维护性、架构设计等）
```

## 三、深度审查模板（深度模式）

适用场景：重要决策、复杂系统、需要自动修订版

### 模板 6：方案深度审查 + 修订

```
帮我用深度模式审查这个商业方案，给我一份完整的审查报告和修订版。

【方案名称】
（名称）

【完整方案】
（粘贴完整方案）

【详细背景】
- 行业/领域：（详细说明）
- 目标用户：（画像越清楚越好）
- 核心目标：（量化目标最好）
- 资源约束：（预算、人力、时间）
- 已有的假设：（你认为成立但可能有争议的前提）

【输出要求】
- 需要自动修订版
- 变更对比表要详细
- 每个问题都要有修改建议
```

### 模板 7：代码深度审查 + 修复

```
帮我用深度模式审查这段代码，发现的问题直接帮我修复，给出修复后的完整代码。

【完整代码】
（粘贴完整代码）

【上下文】
- 语言/框架/版本：（详细说明）
- 功能描述：（这段代码在系统中的作用）
- 技术栈细节：（数据库、缓存、中间件等）
- 已知问题：（如果你已经知道一些问题，列出来）

【输出要求】
- 修复后的完整代码
- 改动位置和原因说明
- 检查是否引入新问题
```

## 四、续审模板

适用场景：上次审查后补充了信息，接着继续审

### 模板 8：补充后续审

```
接着上次的审查继续。我补充了一些信息，你接着之前的结论往下审。

【上次审查的结论摘要】
（简要回顾上次的结论，或者直接引用上次的对话）

【补充的信息】
- （补充的信息 1）
- （补充的信息 2）
- ...

【这次的要求】
（如：重点确认之前标「不确定」的几个问题 / 基于新信息更新修订版）
```

## 五、定向审查模板

适用场景：只想让专家关注某个特定角度

### 模板 9：定向风险审查

```
帮我审查一下这个方案，但重点从风险角度审，其他方面可以简略。

【方案内容】
（内容）

【想关注的风险类型】
（如：合规风险、财务风险、执行风险、竞争风险）
```

### 模板 10：定向安全审查

```
帮我重点从安全角度审查这段代码，其他方面不用太细。

【代码】
（代码）

【安全关注点】
（如：SQL 注入、越权访问、数据泄露、认证绕过）
```

## 六、使用技巧

1. **信息越全越好**：上下文给得越充分，审查越精准，追问越少
2. **明确模式**：直接说「用深度模式」或「快速看一下」，省得系统判断
3. **指定重点**：告诉它你最担心什么，它会调整专家组合和关注点
4. **分块审查**：内容特别长的话，可以先让它快速过一遍，找到重点后再深挖
5. **用好续审**：不用一次把所有信息都给全，先初步审，有问题再补充
