# 飞书智能周报/月报（feishu-weekly-report）

> 自动读取飞书里与你工作相关的文档、会议纪要、任务、多维表格、电子表格、知识库、群聊消息，跨源聚合去重、判定状态，生成一份**有事实依据、可直接向领导汇报**的中文周报或月报。

---

## 一、能解决什么问题

写周报/月报最耗时间的不是"写"，而是**把散落在飞书各处的事找齐、判断真假、串成逻辑**。这个技能把前半段自动化：

- 自动定周期（周报：周一报上周，非周一报本周一至今；月报：月初报上月，其他时间报本月至今）
- 自动读取 8 类飞书数据源（只读，不动你的数据）
- 自动筛出"与我相关 + 周期内有变化"的内容
- 跨源去重、判定状态、脱敏、归类
- 输出双版本：**领导版摘要**（≤8 条要点）+ **完整周报/月报**（8 大板块）

## 二、核心能力（10 项）

| # | 能力 | 说明 |
|---|---|---|
| 1 | 周期自动推断 | 周报：周一→上周一~上周日，非周一→本周一~现在；月报：月初1~3日→上月整月，其他→本月1日~现在；时间用系统命令算，不心算 |
| 2 | 自动读取飞书 | 文档 / 会议纪要 / 任务 / 多维表格 / 电子表格 / 知识库 / 指定群聊，全只读 |
| 3 | 识别工作变化 | 只保留"我相关 + 周期内有新增/修改/完成/延期"的条目 |
| 4 | 跨源聚合去重 | 同一事项在多个来源出现时归并，保留最新状态 |
| 5 | 业务主题归类 | 按项目/事项归类，不按"文档/会议/表格"罗列 |
| 6 | 事实 vs 判断分离 | 三级证据：已核验事实 / 综合判断 / 待确认 |
| 7 | 双版本输出 | 领导版摘要 + 完整周报/月报 8 板块 |
| 8 | 隐私脱敏 | 客户姓名/电话/邮箱/订单号/单条客诉等默认脱敏 |
| 9 | 状态真实性判定 | 6 种状态（已完成/正常推进/有风险/需决策/暂停/信息不足），绝不把"计划"写成"已完成" |
| 10 | 安全写回 | 默认只输出到对话；写飞书前必先预览、经你确认 |

## 三、依赖

| 依赖 | 说明 |
|---|---|
| `lark-cli` | 飞书官方 CLI，认证与命令执行 |
| `lark-unified` 技能 | 统一封装 lark-cli 各业务域命令，认证/身份/JSON 契约以其为准 |

首次使用前需先完成飞书授权：`lark-cli auth login`（技能会按最小权限自动补齐缺失的 scope，不会 `--domain all`）。

## 四、安装

```bash
# 解压后把整个目录放进用户级技能目录即可
unzip feishu-weekly-report.zip -d ~/.workbuddy/skills/
```

安装后目录结构：

```
~/.workbuddy/skills/feishu-weekly-report/
├── SKILL.md                      # 主入口（frontmatter + 五条铁律 + 编排流程）
└── references/
    ├── data-sources.md           # 数据源命令映射 + scope 表 + 相关性过滤 + 链接类型判定
    ├── period-rules.md           # 周期推断规则
    ├── dedup-rules.md            # 跨源去重与状态冲突处理
    ├── status-rules.md           # 状态枚举 + 事实/判断/待确认判定标准
    ├── report-template.md        # 双版本周报模板 + 句式规范
    ├── privacy-rules.md          # 脱敏清单与处理规则
    └── write-back-rules.md       # 写飞书的门槛与安全流程
```

## 五、使用方式

直接在对话里说一句即可触发，无需记命令：

- 「生成这周周报」 / 「写周报」 / 「上周周报」
- 「生成这个月的月报」 / 「上月月报」 / 「本月月报」
- 「帮我汇报一下最近的工作」
- 「把这周会议、任务、表格里的事整理成周报」
- 「把本月会议、任务、表格里的事整理成月报」

## 六、五条铁律（不可违反）

1. **默认只读** —— 不改文档/任务/表格/知识库，不发消息，不建/覆盖文档，除非你明确要求且已确认。
2. **事实与判断分离** —— 禁止编造完成度、金额、业务效果、负责人、截止日期、项目状态、领导意见。
3. **不把"计划/准备/讨论中"写成"已完成"** —— 状态判定只认证据。
4. **最小权限** —— 缺 scope 时精确补授权，绝不 `--domain all`。
5. **时间用系统命令算** —— 周期起止由 `date`/Python 计算，不心算。

## 七、输出格式

- **领导版摘要**：≤8 条核心要点，一句话一条，可直接转发。
- **完整周报/月报**：总体结论 → 关键进展 → 进行中事项 → 风险与判断 → 下期重点 → 需要协作 → 待确认信息 → 来源索引（8 板块）。

每句按「动作 + 对象 + 本周期结果/变化 + 业务影响 + 下一步」组织，事实与判断分开标注来源。月报额外补充**月度累计口径**（本月累计完成数、环比变化），周报不要求。
